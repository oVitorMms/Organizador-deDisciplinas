# Organizador de Disciplinas

Uma aplicação web simples e funcional desenvolvida em HTML, CSS e JavaScript Vanilla para ajudar estudantes a gerenciarem suas matérias, horas de estudo acumuladas e status de conclusão.

## Funcionalidades

- **Cadastro de Disciplinas:** Permite adicionar o nome da matéria, carga horária estudada e se já foi concluída.
- **Persistência de Dados (LocalStorage):** Os dados digitados ficam salvos no navegador, permanecendo disponíveis mesmo após fechar ou recarregar a página.
- **Alternância de Status:** Alterne entre "Pendente" e "Concluído" com apenas um clique.
- **Remoção de Itens:** Exclua disciplinas da lista e atualize o armazenamento local automaticamente.

## Tecnologias Utilizadas

- **HTML5:** Estrutura da página e formulário de entrada.
- **CSS3:** Estilização centralizada e legível.
- **JavaScript (ES6+):** Lógica de manipulação de arrays, eventos do DOM e uso do `localStorage`.
